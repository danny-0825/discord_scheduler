# Skill・Agentを追加・更新するWorkflow

## 手順

1. 対象がSkillかAgentか、または両方かを決める。
2. 適用条件、対象外、入力、出力、権限、書き込み範囲、失敗時の扱いを要件定義に整理する。
3. Skillの`SKILL.md`やAgent定義を変更し、必要な参照docsを`docs/skills/`または`docs/agents/`へ追加する。
4. 実行例または独立した検証で、意図しないタスクへ適用されないことを確認する。
5. docsレビューと実装レビューを行い、更新履歴を追記する。

## 完了条件

- Skill／Agentの責務と権限境界が明確
- 独立性、SubAgent、外部変更、認証情報の扱いが定義されている
- 実際の適用例または検証結果がある
- 対応するラベルと更新履歴がある
