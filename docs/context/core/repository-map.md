# リポジトリ構成要約

| パス | 役割 | 詳細 |
| --- | --- | --- |
| `routes/` | DartのHTTPルート | [コードマップ](../../development/code-map.md) |
| `test/` | Dartテスト | 各テストファイル |
| `docs/` | 要件、設計、Workflow、context | [docs入口](../../index.md) |
| `.agents/skills/` | プロジェクト固有Skill | [Skill docs](../../skills/README.md) |
| `.codex/agents/` | Agent定義 | [Agent docs](../../agents/README.md) |
| `.github/` | Issue/PRテンプレート | GitHub設定 |
| `.obsidian/` | Vault設定 | Obsidian固有設定 |

構成を変更する場合は、詳細なコードマップと影響範囲表を更新し、context要約のリンクを確認する。
